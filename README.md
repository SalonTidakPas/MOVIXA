# MOVIXA Android Starter

Starter prototype for an Android phone and Android TV streaming-app interface.

## Included
- Dark cinema home screen
- Fictional demo movie catalog
- Search and genre filters
- Detail screen
- Android TV launcher category
- Media3 dependencies for future authorized video playback

## Important
This is source code, not a compiled APK. The sample catalog is fictional and the
"Putar demo" button is a placeholder. Add only video streams and metadata that
you own or are authorized to distribute.

## Build
Open this project in Android Studio or use a compatible cloud Android build
workflow. The project uses Android Gradle Plugin 8.7.3, Kotlin 2.0.21, and
compileSdk 35.
